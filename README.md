# Chocolate Sales Analysis 2022–2024

## Overview
Analysis of chocolate sales data across 3 years,
6 countries, 22 products, and 25 salespeople.

## Tools Used
- Microsoft Excel (Power Query, PivotTables, FORECAST.LINEAR)
- Power BI (5-page interactive dashboard with forecasting)

## Key Findings
- Total sales growth: 12.27% over 3 years
- Top country: Australia (18% of total sales)
- Top salesperson: Ches Bonnell
- Deal count stable at 1,094/year — growth from larger orders
- Sales forecast 2025: ~$7.37M
